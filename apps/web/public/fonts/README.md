# Self-hosted Vietnamese fonts

Be Vietnam Pro (regular 400, semibold 600, bold 700) and Lora variable (400–700), downloaded 2026-09-16 from the official Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/bevietnampro
- https://github.com/google/fonts/tree/main/ofl/lora

The adjacent OFL files retain upstream copyright and SIL Open Font License terms. Original TTF glyph sets were converted losslessly to WOFF2 with FontTools; no subset or font design changes. Both families verified against 150 unique Vietnamese precomposed/NFD characters, including combining accent marks. Assets are served by this application; no runtime Google Fonts request.

JetBrains Mono variable (100–800) serves code textareas with the same verified Vietnamese glyph coverage. Source: https://github.com/google/fonts/tree/main/ofl/jetbrainsmono ; license in JetBrainsMono-OFL.txt.
