# Glossary

| Term | Meaning |
| --- | --- |
| Artifact | Immutable playable output from a legacy source or upload |
| Build | Durable record intended to bind a legacy artifact or ENGINE revision to runtime output |
| Canonical document | Validated ENGINE project JSON stored in an immutable revision |
| Capability | Short-lived signed token granting a narrowly scoped artifact read |
| ENGINE | Revision-based canonical authoring source type |
| Legacy source | `UPLOAD`, `CODE`, `STORY`, or `PLATFORMER` workflow |
| Materialize | Explicitly persist an adapted legacy document as an EngineProject |
| Mutation batch | Atomic, idempotent list of typed changes against a base revision |
| Release | Moderated publication record bound to a build |
| Revision | Immutable ENGINE document snapshot with content hash and revision number |
| Stable ID | Persistent domain identity independent of array position |
| Tombstone | Hide an asset from active authoring without deleting retained referenced bytes |
| TFG | Current product/UI brand |
| IndieForge | Legacy technical name retained in packages, cookie, database defaults, and volumes |
